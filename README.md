## What it includes
- 32-item Human ESG Scan
- 8 domains and automatic scoring
- primary / secondary / strength profile
- 7-day action plan
- 4-week roadmap
- desktop keyboard support: 1–5 answer keys and arrow navigation
- responsive desktop/tablet/mobile UI
- 4-page A4 PDF personal result report generated in the browser
- mobile share-sheet support when the browser supports file sharing
- interpretation & use guide with print/PDF support
- browser-local result storage in this public demo

## PDF behavior
- Desktop/Android: creates a PDF Blob and downloads it when supported.
- iPhone/iPad: uses the Web Share file sheet when supported, allowing Save to Files/share; otherwise falls back to browser download/print.
- Last fallback: browser Print / Save as PDF.

## Important
This is a public proposal/pilot experience, not BMT's official production HR/medical system. It is non-diagnostic, non-medical, and not for employment decisions. Pilot support-intensity thresholds and retest change values are operational heuristics, not validated clinical cutoffs.
