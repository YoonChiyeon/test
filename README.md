## What it includes
- 32-item Human ESG Scan
- 8 domains and automatic scoring
- primary/secondary/strength profile
- 7-day action plan
- 4-week roadmap
- mobile-first responsive UI
- browser-local result storage in this public demo

## Important
This is a public proposal/pilot experience, not BMT's official production HR/medical system. It is non-diagnostic, non-medical, and not for employment decisions.
